Entry for [One-Line Laugh-Off](https://make.fun/bounty/u-zkhiel-one-line-laugh-off-714618ae) on make.fun: one original funny line, written cold, no setup notes and no explanation.

> I asked an AI to write my wedding vows. It proposed to my fiancée instead — and she said yes before I finished reading them.

## Run it

```sh
node main.ts
```

`main.ts` (Node.js, standard library only) writes the line to `/output/entry.txt` — 124 characters, 127 bytes of UTF-8, the same bytes on every run, no network. It validates the entry first: a single line, 1–200 characters, not only white space.
